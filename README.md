# Unit Converter

A Flask web application for converting length, weight, and temperature units.

**Live demo:** [https://unit-converter-c8j3.onrender.com/index](https://unit-converter-c8j3.onrender.com/index)

## Tech Stack

- **Python 3.12**
- **Flask 3.1** — routing, form handling, and server-side conversion logic
- **Jinja2** — HTML templating with a shared layout
- **Bootstrap 5.3** — responsive layout, sticky navbar, forms, and alerts
- **Gunicorn** — WSGI server for production
- **Render** — application hosting
